# Compêndio O Chamado

## Aviso Legal & Conteúdo Não Oficial

Este é um projeto 100% feito por fãs, sem qualquer fim lucrativo ou intenção de comercialização.

Todo o conteúdo aqui reunido é não oficial e foi desenvolvido para uso em mesa. Ordem Paranormal RPG é uma obra criada por Rafael Lange (Cellbit) e publicada pela Jambô Editora. Todos os direitos sobre o universo, regras-base e marcas registradas pertencem aos seus respectivos criadores.

## Sobre o Projeto

Este projeto nasceu da mesa de RPG O Chamado RPG, um grupo de amigos que joga campanhas juntos há anos.

Ao longo desse tempo, criamos inúmeras regras da casa, trilhas extras, itens amaldiçoados e novos conceitos para expandir nossas histórias. Todo esse material ficava espalhado em documentos soltos, tornando a consulta lenta.

Este site foi criado exclusivamente para reunir, organizar e facilitar o acesso a todo esse conteúdo em um só lugar, tanto para os jogadores quanto para o mestre.

## Créditos

- **Criação & Desenvolvimento:** Jogadores de O Chamado RPG & Companhia
- **Sistema Base:** [Ordem Paranormal RPG](https://ordemparanormal.com.br/) (Jambô Editora / Cellbit)
